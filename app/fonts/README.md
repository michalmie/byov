# Bundled fonts

These unmodified fonts come from the Google Fonts repository and are included
locally so development, production builds and Factory checks need no font download.

- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- IBM Plex Mono: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Both use the SIL Open Font License. Their accompanying OFL files retain the
copyright notices and license terms. Keep those files when redistributing fonts.
